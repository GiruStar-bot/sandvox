# Data sources and their terms

The code in this repository is under the Apache License 2.0 (`LICENSE`).
**The input data under `data/modern/` is not all under Apache-2.0.** Each value keeps the terms of its publisher, listed below.
Every numeric leaf names its source in `data/modern/SOURCES_D477.csv`.

Most values are edited by this project (aggregated, split, aged or converted). For Japanese government data:
「出典：<publisher>『<product>』を加工して作成」 ("Source: <publisher>, <product>; edited by Laplace's Sandvox").

## Status
- **Open** (`SHIP`): Japanese government data under 公共データ利用規約 第1.0版 (PDL1.0) or the e-Stat terms (both compatible with CC BY 4.0), CC BY 4.0, public domain and similar open terms.
- **Single facts** (`DERIVED-ONLY` and `CHECK` rows): the repository holds only single cited values (one rate, one count, one share) and our own derived tables, never the publisher's tables. We treat these as facts. Their terms are still under review; see the table.
- **Not included:** two tables copied whole from sources whose terms do not allow redistribution, the IEA *World Energy Outlook 2022* annex cost table (`r56.json`, `src/R56_values.csv`) and the SIA/BCG exhibit shares (`src/R54_compute_shares.csv`). The 2022 world cost layer (`sim/modern/modern_costs.gd`, `modern_world.gd`) needs `r56.json` and does not run without it; the Japan 2025 core does not use it.
- **Removal requests:** if you hold rights in a value here and want it removed or attributed differently, please open an issue.

This list comes from a licence audit made for this release (2026-11-03). It is not legal advice.
